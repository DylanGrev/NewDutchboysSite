##Projectgegeven
Naam van het project: Dutch Boys website verbeteren

Beschrijving van het project:
De bedoeling van dit project is dat ik een verbetering maak van de huidige website van de dutchboys maak. De bedoeling wordt dat de bezoeker op de site een betere ervaring krijgt, hiervoor wil ik een werkende agenda en een nieuws pagina er bij maken.

De reden(en) waarom je dit project wilt maken:
De rede van dit project is omdat ik zelf heel veel in deze muziek wereld zit en van de stijl hou en websites bouwen wel heel leuk vindt.

Beschrijving van de randvoorwaarden:
In de website moet een werkende agenda komen waar je als administator bij kan om een locatie een organisatie(bijvoorbeeld Mega piraten festijn, TukkerFM ETC), een tijdslot en een prijs als dit van toepassing is.
Een werkende nieuws pagina waar de administratie een nieuws artikel kunnen toevoegen van een externe of interne pagina. De bedoeling hiervoor is dat de administratie een text kan invullen en eventuele plaatjes boven en onder de text en daarmee een nieuwe pagina maakt voor het nieuws.

Denk aan AVG, Copyright, Licenties, Wettelijke impact, Maatschappelijke impact:
Er zijn wel Copyrights van toepassing en licenties omdat dit natuurlijk met een artiesten naam en plaatjes te maken heeft. 
Er is niet echt een wettelijke impact maar wel een maatschappelijke voor de mensen die deze band natuurlijk volgen.

mijn datum waar ik op wil beginnen wordt 15-09(september)-2026 tot 13-10(oktober)-2026
